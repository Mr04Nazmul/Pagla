# Pagla — 3D model provenance and licences

The game downloads these **real GLB files** from `cdn.3dassets.dev` at runtime through Three.js `GLTFLoader` and places them into the scene. These are not HTML mockups or placeholders. The models are not stored in this Git repository; offline play of streamed GLB assets is not guaranteed.

3DAssets.dev publishes these specific assets as **CC0 1.0 Universal**, including commercial use and modification with no mandatory attribution. See https://creativecommons.org/publicdomain/zero/1.0/ . The links are retained below for transparency. All listed models were generated with AI-assisted tools per the model authors' metadata.

**Other visuals:** Terrain, mud, roof and grass materials, sky, character meshes, field geometry, puddles, water, buildings, props, signs, utility poles and vehicle fallback meshes are generated by Pagla's own project code. No third-party proprietary textures, Sketchfab CC BY models or GTA artworks were copied into the repository. Native material textures are generated on canvas as procedural noise. Externally loaded GLBs include their own embedded materials/textures.

**Libraries:** Three.js is MIT licensed. Version is pinned in the HTML import map; see https://github.com/mrdoob/three.js/blob/master/LICENSE .

**Hosting/runtime limitation:** The game relies on network access to `cdn.jsdelivr.net` for Three.js and `cdn.3dassets.dev` for models. If models fail to load, core game still runs with generic fallback environment and vehicles. If the Three.js import itself is blocked, the player can use `legacy.html` instead. Performance is device-dependent.
